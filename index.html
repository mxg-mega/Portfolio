About

I started in biochemistry, ended up shipping software — turns out the same instinct that runs a controlled experiment runs a clean build: define the system, isolate the variables, test it, ship it.

Today that shows up as BizMod, a modular SaaS platform I designed and built solo across 15 production modules, plus a run of Flutter apps built for real, specific problems rather than portfolio filler. I'm currently building GPIA, a Python agent that reads a GitHub profile and writes the CV to match it — because I got tired of doing that by hand.

Game development is the newest track: same engineering discipline, aimed at something that's supposed to be fun instead of useful.
